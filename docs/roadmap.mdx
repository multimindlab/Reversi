## Built

Manifests, write-ahead ledger, dependency-aware rollback with retries, verification and reconciliation, scopes, approvals
(queued, argument-bound, single-use, expiring, persisted, notified), observe mode, [policy as code](/concepts/policy),
[content checks](/concepts/content-checks), kill switch, secret redaction, [signed evidence](/concepts/evidence) and reports,
files / SQLite / PostgreSQL stores, HTTP API with [roles, key rotation and OIDC](/operations/authentication), the
[operator console](/console), Prometheus metrics, the [MCP gateway](/gateway) (enforce and observe, multiple upstreams,
allow/deny, approvals, operator endpoint with rollback tools, Streamable HTTP with auth), [connectors](/connectors) for
filesystem, GitHub, Slack and Stripe, the CLI, the Python SDK, the trace viewer, Docker and CI definitions.

## Not built

- OpenTelemetry traces (Prometheus metrics and JSON logs exist).
- Risk scoring, delegated approval and break-glass flows beyond the single approver role.
- Retention and purge tooling, legal hold, data residency controls.
- Gateway: resources, prompts and sampling passthrough; clustering with run hand-off.
- More connectors (Linear, Jira, Calendar, PostgreSQL, Salesforce, cloud providers) and a connector certification suite.
- Framework adapters (LangGraph, CrewAI, OpenAI Agents) and Go/Java SDKs.
- Speculative execution and branch comparison.
- Helm chart, external anchoring service, hosted control plane.
- An external security review of the code.
