```python
from reversi_sdk import ReversiClient, Blocked, EffectUncertain

client = ReversiClient("http://127.0.0.1:7421", api_key="agent-key")
run = client.start_run(["orders:write"], reason="support chat 4821")

try:
    order = run.call("create_order", "customer asked for BOOK-1",
                     lambda args: shop.create_order(**args), args={"sku": "BOOK-1"})
except Blocked as e:
    print("refused:", e.reasons)       # the tool never ran
```

`call` journals the intent **before** running your function and the outcome after. Raise `EffectUncertain` when you
cannot tell whether the effect happened.

Decorate tools so every call goes through the run:

```python
@run.tool("create_order", "customer asked")
def create_order(args): ...

create_order({"sku": "BOOK-1"})
```

## Approvals

When a call needs approval, `Blocked.approval_id` holds the request id. Ask an approver to decide it, then retry the same call:

```python
try:
    run.call("refund", "customer asked", do_refund, args={"amount": 500})
except Blocked as e:
    notify(e.approval_id)

approver = ReversiClient(url, "approver-key")
approver.approvals(status="pending")
approver.approve(approval_id, "checked the ticket")        # or approver.deny(...)
```

## Operator methods

With an operator key: `run.plan()`, `run.rollback(compensate, attempts=3)` (retries with backoff and the **same**
`call["idempotency_key"]`; returns a report whose `complete` is true only if nothing was left undone), `run.resolve(step,
"succeeded", note, result=…)` for unknown outcomes, `run.begin_compensation` / `complete_compensation` for custom workers,
`run.export_jsonl()`, `run.report_html()`, `run.bundle()` (signed evidence). With an admin key: `client.halt(reason)` and
`client.resume()`. Auditors can use `client.approvals()`, `client.status()`, `client.verify_ledger()`, `client.ledger_bundle()`.

Verify bundles with `reversi verify-bundle`: Ed25519 is not in the Python standard library.

## Offline tools (no server)

```python
from reversi_sdk import verify_file, validate_manifest
print(verify_file("ledger.jsonl"))
manifest, errors = validate_manifest({"tool": "x", "effect": "read_only", "permission": "p"})
```

`python -m reversi_sdk verify ledger.jsonl` works from a shell. The Python validator and verifier are tested against
the TypeScript implementation on shared fixtures. Manifests are read from JSON; convert YAML first.

<Note>
Canonical JSON for payload hashing rejects non-whole floats outside 1e-4 to 1e16, where Python and JavaScript format
numbers differently. Pass such values as strings.
</Note>
